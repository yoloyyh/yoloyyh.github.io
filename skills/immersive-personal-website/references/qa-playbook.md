# 沉浸式个人站验收清单

## 连贯性

- 从首页进入场景、打开项目/文章、返回场景，再次进入；至少连续走两轮。
- 对比背景、门、光点、人物终点与路径是否重合；调整视口、旋转手机或改变浏览器高度后重新检查。
- 背景慢加载或失败时，不出现漂浮在空白上的错误热点；主要文本和入口保持可用。
- 城堡内部的楼梯应有落地入口、连续踏步、支撑、扶手和与上层走廊的连接。不要以画面精美代替结构检查。

## 设备、交互与声音

- 检查小屏按钮、弹层、卷轴、图片、文章表格和长链接是否溢出；书写羽毛和关闭按钮是否可见。
- 打开、关闭、快速重复打开；键盘与触屏可用；关闭后焦点和滚动位置合理。
- 检查系统减少动态效果、浏览器自动播放策略和音乐开关；音效应与操作同时开始并在结束时停止。

## 内容与发布

- 点击项目卡应抵达正确公开仓库；Fork 和外部项目要有本人提交证据，并按仓库关系去重。
- 本地和公开文章要按标记隔离；校验部署产物只含允许公开的内容。取消标记后检查导出结果，并说明线上缓存及 Git 历史。
- 检查原文链接、Markdown 格式、文章目录、语言切换和真实资料来源；不为缺失数据虚构简介。
- 部署前检查音乐、音效和图片的公开使用条件；部署后核对 Actions 与实际页面，不以推送成功等同于上线成功。
